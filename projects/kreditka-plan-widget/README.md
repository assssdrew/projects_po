# Виджет «Кредитка · план» — Scriptable

Матрица погашения Т-Банк Платинум по **календарю** (VND переведены в ₽).

## v2.1

- База: события Google Calendar (приходы/траты авг–сен 2026)
- ₫ → ₽ по курсу (~0,00322 ₽/₫)
- **Один экран:** матрица + ввод расхода/погашения/снятия, пересчёт сразу
- Close сохраняет суммы

Таблица пересчёта: `notes/calendar-cashflow-rub.md`.

## Плитка

| Дата | Снятие | Погаш | Долг |

Без заголовка, на всю ширину, padding 12 pt.

## Меню (тап / ▶ Play)

- Матрица
- Ввести суммы
- + расход / + погашение / + снятие
- флаг +10к

## Установка

1. Scriptable → скрипт `KreditkaPlan` → код из `KreditkaPlan.js` → ▶ **Play**
2. Меню должно показать **v2.0**
3. Home Screen → Scriptable → Medium/Large
