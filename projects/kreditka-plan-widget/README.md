# Виджет «Кредитка · план» — Scriptable

Компактная таблица погашения Т-Банк Платинум на Home Screen.

Стек как у `../vocab-iphone-widget/`: приложение **Scriptable**, JS-скрипт.

## Что на плитке (матрица)

| Колонка | Смысл |
|---------|--------|
| Дата | 16.08 → 29.09 |
| Снятие | операции с кредитки (+долг) |
| Погаш | пополнения кредитки (−долг) |
| Долг | остаток после операции |

Large — все даты. Medium — даты со снятием/погашением + ключевые точки.  
Внизу: `Σ погаш · Σ снят · % · хвост`.

Чипы флагов: `●+10к  ○велик↓  ○буфер  ●еда`.

Тап → полная матрица: Дата | Заметка | Приход | Нал.расход | Снятие | Погашение | % | Долг.

## Флаги (тап по виджету или ▶ Play)

| Флаг | Эффект |
|------|--------|
| **Снятие +10 000** | старт 110к вместо 100к |
| **Отложить велик** | +6к к взносу 05.09 |
| **Микробуфер** | взнос 25.08 = 13к вместо 15к |
| **Честная еда** | еда 7,5к (10.09) и 17,5к (25.09) → меньше на карту |

Пересчёт мгновенный в таблице; после закрытия экрана флаги сохраняются и виджет обновится при следующей отрисовке.

## Установка

1. App Store → **Scriptable**
2. Новый скрипт → имя `KreditkaPlan` → вставь код из `KreditkaPlan.js` → ▶ **Play**
3. Home Screen → Edit → **+** → Scriptable → Medium/Large → скрипт `KreditkaPlan`
4. Тап по виджету → «Таблица + флаги» или быстрые переключатели

Принудительное обновление ядра: скрипт `UpdateKreditkaPlan.js`.
