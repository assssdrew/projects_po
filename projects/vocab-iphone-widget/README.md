# Виджет «Слово» — что это и как пользоваться

## Где мы сейчас
Учим слова из словаря на **iPhone**:
- виджет показывает слово + перевод
- тап → отметки (увидел / выучил / повторил)
- все 3 статуса → следующее слово
- **транскрипция** (если нашлась в словаре)
- кнопка **🔊 Произнести** (голос iPhone)

## Обновить на телефоне (проверка)
1. Открой Scriptable → скрипт **WordOfDay**
2. Нажми **▶ Play** (справа вверху)
3. Тапни виджет или снова Play → увидишь меню с **🔊 Произнести** и транскрипцией

Копировать код заново не нужно (репозиторий уже Public).

## Установка с нуля (если ещё нет)
1. Создай скрипт `WordOfDay`, вставь `WordOfDay.js` один раз
2. Play ▶
3. Виджет Scriptable → выбрать `WordOfDay`
