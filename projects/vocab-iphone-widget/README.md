# Виджет «Слово» — пассивный

Слово всегда на экране. Кнопок нет — ничего нажимать не нужно.

## Как работает
- На виджете: английское слово, транскрипция, перевод
- Само меняется **каждые 4 часа**
- Смотришь на телефон → уже учишь

## Установка / обновление
1. Scriptable → скрипт **WordOfDay**
2. Вставь код из `WordOfDay.js` (короткий bootstrap)
3. ▶ **Play** один раз (скачается новая версия)
4. Добавь виджет Scriptable на домашний экран и/или экран блокировки
5. В настройках виджета выбери скрипт **WordOfDay**

Рекомендуется размер **средний** или **большой** (на маленьком перевода может не быть).

## Редкие действия (необязательно)
▶ Play в Scriptable:
- следующее слово сейчас
- произнести
- история
- сброс

В обычной жизни в Scriptable заходить не нужно.
