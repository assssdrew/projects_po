# Виджет «Слово» — пассивный

Слово всегда на экране. Кнопок нет.

## Как выглядит
- **Английское** — крупно, жирно
- **Перевод** — меньше
- Фон **прозрачный** (видны обои)
- Без транскрипции и без примеров

Смена слова каждые **4 часа**.

## Обновить
1. Замени код `WordOfDay` на `WordOfDay.js`
2. ▶ **Play**
3. Внизу виджета должно быть **v3**
