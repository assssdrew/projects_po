# Виджет «Слово дня» для iPhone (Scriptable)

Одно слово в день на домашнем экране + отметки **увидел / выучил / повторил**.

## Два скрипта

| Файл | Зачем |
|------|--------|
| `UpdateWordOfDay.js` | **короткий апдейтер** — вставил, Play, код в буфер |
| `WordOfDay.js` | основной виджет (длинный, со словарём) |

## Как обновлять (как часы/шаги)

1. В Scriptable открой скрипт **UpdateWordOfDay** (вставь короткий код из `UpdateWordOfDay.js`).
2. Нажми **Play ▶**.
3. Полный код виджета попадёт **в буфер обмена**.
4. Открой **WordOfDay** → вставь из буфера → Done.
5. Виджет на экране привяжи к `WordOfDay`.

> Репозиторий GitHub **приватный**, поэтому апдейтер качает код с публичной ссылки dpaste (не с raw.githubusercontent.com).

## Что умеет виджет

- слово дня из словаря (~948)
- на medium/large — перевод
- тап → увидел / выучил / повторил + история
- прогресс локально на телефоне

## Ограничения

- не блокирует экран
- пока без Anki-повторов
- апдейтер качает код с GitHub (нужен интернет)
