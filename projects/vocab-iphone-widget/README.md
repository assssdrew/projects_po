# Виджет «Слово»

## Как пользоваться
На виджете кнопки:
- **🔊** произнести
- **👁** увидел
- **✅** выучил
- **🔁** повторил

Все три статуса → следующее слово.

## Обновить
Scriptable → **WordOfDay** → **▶ Play**

## Заметка
iOS всё равно на мгновение открывает Scriptable при нажатии кнопки виджета — это ограничение системы. Большого меню больше нет: действие выполняется сразу.
