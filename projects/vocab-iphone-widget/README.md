# Виджет «Слово» для iPhone (без копирования)

## Как пользоваться (просто)

1. Установи **Scriptable**.
2. Создай скрипт **WordOfDay**, вставь **короткий** код из `WordOfDay.js` **один раз**.
3. Нажми **Play ▶** — сам скачает большой код (словарь + логика).
4. Добавь виджет Scriptable → выбери **WordOfDay**.

### Обновления кода
Больше **не нужно** копировать из буфера.
Просто открой **WordOfDay** → **Play ▶** (или тапни по виджету) — свежий код скачается сам.

### Логика слов
Отметь все три статуса (увидел / выучил / повторил) → сразу следующее слово из списка.

## Файлы
- `WordOfDay.js` — короткий bootstrap (вставляешь один раз)
- `WordOfDayCore.js` — полная логика + словарь (качается автоматически)
- `vocabulary.json` — словарь отдельно
