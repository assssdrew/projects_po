# Виджет «Слово» — без постоянного копирования

## Главное

Короткий скрипт `WordOfDay.js` вставляется **один раз**.  
Дальше обновления = только **Play ▶** (код качается сам).

Чтобы так работало навсегда, репозиторий `projects_po` должен быть **Public**  
(иначе GitHub не отдаёт файл по ссылке).

GitHub → `projects_po` → **Settings** → **Danger zone** → **Change visibility** → **Public**.

## Установка один раз

1. Scriptable → создай скрипт `WordOfDay`
2. Вставь содержимое `WordOfDay.js`
3. Сделай репозиторий Public (см. выше)
4. **Play ▶**
5. Виджет Scriptable → выбери `WordOfDay`

## Каждый день

Тап по виджету → отметки.  
Все 3 статуса → следующее слово.

## Обновить логику/словарь

Открой `WordOfDay` → **Play ▶**. Ничего не копируй.
