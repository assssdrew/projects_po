# Виджет «Слово дня» для iPhone (Scriptable)

Прототип варианта D: одно слово в день на домашнем экране + отметки **увидел / выучил / повторил**.

Работает через бесплатное приложение [Scriptable](https://apps.apple.com/app/scriptable/id1405459188) — без Xcode и App Store своей сборки.

## Что умеет

- Виджет показывает **слово дня** (из `vocabulary_full.md`, ~950 единиц)
- На среднем/большом виджете виден **перевод**
- Тап по виджету → меню отметок и история
- Прогресс хранится локально на телефоне

## Установка (5 минут)

1. Установи **Scriptable** из App Store.
2. Скачай файл `WordOfDay.js` из этой папки (или скопируй его содержимое).
3. На iPhone: открой `WordOfDay.js` → «Поделиться» → **Scriptable** → **Add to My Scripts**.  
   Либо в Scriptable: «+» → вставь код → сохрани с именем `WordOfDay`.
4. На домашнем экране: зажми пустое место → **+** → найди **Scriptable** → виджет (лучше Medium) → **Добавить**.
5. Зажми виджет → **Изменить виджет** → Script: **WordOfDay**.

Готово: каждое утро (новый календарный день) — новое слово по очереди.

## Как пользоваться

| Действие | Результат |
|----------|-----------|
| Тап по виджету | Открывается меню |
| 👁 Увидел | слово отмечено как просмотренное |
| ✅ Выучил | увидел + выучил |
| 🔁 Повторил | повтор через время |
| 📜 История | последние слова и статусы |

## Файлы

- `WordOfDay.js` — скрипт виджета (слова уже внутри)
- `vocabulary.json` — тот же список отдельно (для будущих версий)
- Этот `README.md` — инструкция

## Ограничения прототипа

- Не блокирует экран телефона (это следующий этап)
- Нет умных повторов Anki — пока строго «1 новое слово / день»
- Виджет обновляется при тапе и периодически системой iOS
