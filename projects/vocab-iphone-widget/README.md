# Виджет «Слово дня» для iPhone (Scriptable)

Одно слово в день на домашнем экране + отметки **увидел / выучил / повторил**.

## Два скрипта

| Файл | Зачем |
|------|--------|
| `UpdateWordOfDay.js` | **короткий апдейтер** — вставил, Play, код в буфер |
| `WordOfDay.js` | основной виджет (длинный, со словарём) |

## Как обновлять (как часы/шаги)

1. В Scriptable открой скрипт **UpdateWordOfDay** (или создай новый и вставь короткий код из `UpdateWordOfDay.js`).
2. Нажми **Play ▶**.
3. Полный код виджета окажется **в буфере обмена** (и файл `WordOfDay.js` перезапишется, если он есть в Scriptable).
4. Открой основной скрипт **WordOfDay** → вставь из буфера → Done.
5. На виджете: зажми → **Обновить виджет** (если нужно).

Первая установка: один раз создай пустой скрипт `WordOfDay`, потом прогони апдейтер и вставь код из буфера. Виджет на экране привяжи к `WordOfDay`.

## Что умеет виджет

- слово дня из словаря (~948)
- на medium/large — перевод
- тап → увидел / выучил / повторил + история
- прогресс локально на телефоне

## Ограничения

- не блокирует экран
- пока без Anki-повторов
- апдейтер качает код с GitHub (нужен интернет)
