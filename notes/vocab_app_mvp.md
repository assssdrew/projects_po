# Прототип: слово на iPhone (вариант D)

## Как обновляется код

Короткий скрипт `WordOfDay.js` вставляется **один раз**.  
При **Play** или **тапе по виджету** сам скачивает `WordOfDayCore.js` (словарь + логика).  
Копировать большой код вручную не нужно.

## Логика слов

Текущее слово на виджете.  
Отметки: увидел / выучил / повторил.  
Когда все три стоят → сразу следующее из списка.

## Файлы

- `projects/vocab-iphone-widget/WordOfDay.js` — короткий bootstrap
- `projects/vocab-iphone-widget/WordOfDayCore.js` — полная логика
- `notes/vocabulary_full.md` — исходный словарь
