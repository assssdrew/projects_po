# Прототип: слово дня (вариант D)

Цель: простой цикл «увидел → отметил → повторил», без игр и жёсткого lock. Потом можно нарастить.

## Источник слов

Файл: `notes/vocabulary_full.md`  
Формат строк: `слово — перевод`

## Что входит в MVP

1. **Одно слово в день** (по очереди из списка, без повторов, пока список не кончится).
2. **Экран / виджет** показывает:
   - английское слово (или фразу);
   - перевод (можно скрыть тапом «показать»).
3. **Три отметки** по текущему слову:
   - увидел;
   - выучил;
   - повторил.
4. **История**: список уже показанных слов + статусы.
5. **Кнопка «следующее»** — только после «увидел» (или в конце дня автоматически).

## Что НЕ входит в MVP

- блокировка экрана телефона;
- Anki-алгоритм / интервальные повторения;
- голосовой ввод, игры, стрики, пуши (можно добавить позже);
- аккаунт / облако (сначала локально на устройстве).

## Минимальные экраны

1. **Сегодня** — слово, перевод (скрыт/открыт), 3 галочки.
2. **История** — список слов со статусами.
3. **Настройки** (опционально) — сброс прогресса, «показать перевод сразу: да/нет».

## Логика дня

```
если нет слова на сегодня:
  взять следующее неиспользованное из vocabulary_full.md
  сохранить как «слово дня» + дата
показать слово
пользователь отмечает: увидел / выучил / повторил
завтра — новое слово (вчерашнее остаётся в истории)
```

## Данные (локально)

- очередь слов (из md);
- текущий индекс / дата слова дня;
- статусы по каждому слову: `seen`, `learned`, `reviewed` (bool + дата).

## Платформа (решить галочками ниже)

Прототип должен открываться на телефоне; виджет — вторым шагом после рабочего экрана «Сегодня».

## Критерий «прототип готов»

- [ ] Слово дня берётся из списка
- [ ] Перевод можно скрыть/показать
- [ ] Три отметки сохраняются
- [ ] История показывает прошлые слова
- [ ] После перезапуска приложения прогресс не теряется
