# Прототип: слово дня на iPhone (вариант D)

Цель: простой цикл «увидел → отметил → повторил» через **виджет на домашнем экране**.

## Платформа

**iPhone-виджет** через [Scriptable](https://apps.apple.com/app/scriptable/id1405459188)  
Код: `projects/vocab-iphone-widget/WordOfDay.js`

Почему так: виджет ставится за минуты, без Xcode и публикации в App Store. Позже можно перенести в нативное приложение (WidgetKit).

## Источник слов

`notes/vocabulary_full.md` → встроен в `WordOfDay.js` (~950 пар).

## Что входит в MVP

1. **Одно слово в день** на виджете (по очереди из списка).
2. Виджет показывает слово; на medium/large — и перевод.
3. Тап по виджету → отметки:
   - увидел;
   - выучил;
   - повторил.
4. **История** прямо в меню Scriptable.
5. Прогресс сохраняется локально на телефоне.

## Что НЕ входит в MVP

- блокировка экрана iPhone;
- Anki / интервальные повторения;
- голосовой ввод, игры, пуши;
- iCloud-синхронизация между устройствами (пока local storage).

## Критерий «прототип готов»

- [x] Слово дня берётся из списка
- [x] Виджет на домашнем экране
- [x] Три отметки сохраняются
- [x] История доступна
- [x] После перезапуска прогресс не теряется
