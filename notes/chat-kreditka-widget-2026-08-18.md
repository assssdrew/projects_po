### 2. UX-круги (что просили и что откатывали)

Порядок важен: несколько раз возвращались к полной прокручиваемой матрице.

1. **v1.x** — полная матрица + флаги. v1.3 «сжать» — плохо, откат к v1.1/v1.2.
2. **v2.x** — календарь с FX + один экран. «Вместить без скролла» (`fitLayout`) **растягивал строки** и обрезал Close/таблицу.
3. Просьбы по продукту: не двигать цифры календаря; галочка «школа ½»; компактные строки как в v1.1; вернуть **полный скролл**.
4. Дальше косметика: меньше карточки; убрать серый подзаголовок и текст под таблицей; галочки **по две в ряд**.
5. Safe-area: `padding-top: calc(env(safe-area-inset-top) + 44px)` + `fitChrome()` (если `visualViewport.offsetTop > 8` → 8px, иначе safe+44, min 98px), чтобы Close не накрывал ввод и заголовок не уезжал в статус-бар.
6. Строка **переплата %** (`interestTotal`) внизу таблицы.
7. Галочку **«Школа 05.09» / `schoolLater` сняли** — школа остаётся **31.08**.
8. Ручные суммы: pills с ×; в таблице у своих строк × в колонке «Что»; `addCustom()` ругается, если нет даты/суммы; сумма принимает `5к`.

### 3. Дата не добавлялась (v3.7)

iOS `inputmode="numeric"` **блокирует точку**. `iso()` не парсил `20.09`, строка не появлялась.

Исправление: `inputmode="decimal"` + парсер принимает `20.09` **или** `2009` (=20.09), `3108` (=31.08). Коммит `667fd44`.

### 4. Скрин 1 — ошибка importModule (~01:33 UTC)

Лог Scriptable:

```
Error on line 99:26 in KreditkaPlanCore module
TypeError: undefined is not an object (evaluating 'importModule("KreditkaPlanCore")')
```

В редакторе был **старый** `KreditkaPlan.js` v1.0:

- комментарий «меню Кредитка - План v1.0+»
- `const CORE_URLS = {` (объект) или позже массив, но в конце всё равно `importModule`
- строка 99 оригинала: `const core = importModule("KreditkaPlanCore");`

Почему падает: загрузчик пишет `KreditkaPlanCore.js` и в **том же запуске** вызывает `importModule`. Scriptable модуль не индексирует (особенно iCloud) → `undefined`. Смена только URL в `CORE_URLS` это не лечит.

В репозитории к этому моменту загрузчик уже был на `new Function`, без `importModule`. На телефоне файл **не заменили целиком**.

Дополнительно в ядре всплыл мёртвый хвост после `toISO()` (лишние `const mm` / `return`) — SyntaxError при разборе. Убрали.

Попытка фикса: **standalone v3.8** — весь виджет в одном `KreditkaPlan.js` (`KREDITKA_STANDALONE = "3.8"`, `await main()`, без `importModule`). Коммит `2d81c30`.

### 5. Скрин 2 — та же ошибка (~01:43 UTC)

Снова v1.0. Заголовок скрипта в UI обрезан до **«Kredit»**. Комментарий точный: «меню Кредитка · план · v1.0». `CORE_URLS = [` (массив, URL ветки уже наш), но строка 99 всё ещё `importModule`.

Вывод: длинный standalone с телефона, скорее всего, **не вставлялся**. Правили только ссылку в старом коротком файле.

Второй фикса:

- вернули **короткий LOADER 3.8** (~130 строк, как v1.0 по размеру): `const LOADER_38 = true`, скачивает ядро, гоняет через `new Function` / async IIFE (чтобы в ядре можно было `await`)
- `KreditkaPlanCore.js` сам запускает `main()`, если скрипт открыт как `KreditkaPlanCore*`
- обход без замены загрузчика: открыть **KreditkaPlanCore** → Play

Коммит `6764ad2`.

## Версии ядра (цепочка комментариев)

Актуальная: **3.8**. jsDelivr убрали — отдавал протухшее ядро. Только GitHub raw ветки + `?t=Date.now()`.
