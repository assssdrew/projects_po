# Максимально удобное и недорогое погашение (авг–сен 2026)

Исходники: issue #7, календарь 17.08, тариф ТП 7.118.  
Даты приходов **не сдвигаем**. Школу 31.08 трогаем только галочкой в таблице.

## Почему не «всё на карту с каждой ЗП»

Грейс к **29.08** уже не спасти (~100к нечем закрыть). Дальше **59,9% ≈ 16,4 ₽/день на каждые 10к**.  
Но класть ЗП 25.08 целиком на карту — хуже: 31.08 школа ≈ **76к**, придётся снимать обратно → комиссия **2,9%+290** и долг снова выше.

## Три запрета

1. Не снимать и не переводить с Платинум школу / квартиру / КУ / «ещё +10к».
2. Не класть на карту деньги, которые через несколько дней нужны на школу.
3. После 29.08 остаток на карту **в день ЗП**, не ждать 29-го.

## Рекомендуемый режим (галочки в виджете)

| Галочка | Рекомендация | Зачем |
|---------|--------------|--------|
| Снятие +10к | **выкл** | комиссия + % сразу |
| Школа ½ с мамой | **вкл, если договоритесь** | самый большой рычаг: дыра 31.08 ≈ 23к пропадает |
| Отложить байк | **вкл** | ≈ 6,4к не из кредитки |
| Честная еда | **вкл** | 7,5к (10.09) + 17,5к (25.09), иначе хвост «рисуется» нулевым |
| Школа 05.09 | **вкл, если мама не делит** | школа с ЗП 05.09, без снятия 31.08 |

## Ожидаемый хвост 29.09 (модель виджета v3, курс 0,00322)

| Сценарий | Снятия | Хвост 29.09 | % за путь |
|----------|--------|-------------|-----------|
| Календарь + честная еда | ~46к (школа/КУ) | **~57к** | ~5,3к |
| **½ школа + без байка + честная еда** | ~2к | **~11к** | ~3,2к |
| Школа 05.09 + без байка + честная еда | ~0,3к | ~50к | ~4,5к |
| Ещё и +10к снятие | ещё хуже | ~57к+комиссия | не делать |

**Главный рычаг — школа ½ с мамой.** Сдвиг школы на 05.09 экономит комиссию (нет дыры 31.08), но ЗП 05.09 уходит в школу, а не в долг — хвост остаётся большим.

Цель «≈ 0 к 29.09» из первой выжимки **завышена**, если есть честная еда и школа 31.08 целиком.
