# Конвертер валют: варианты реализации (от простого к сложному)

Все варианты ниже **бесплатны** (без обязательных платных подписок). Платные шаги
помечены отдельно — они нужны только для публикации в App Store / Google Play,
для личного использования на своём телефоне они не требуются.

Источники курсов валют — бесплатные, без карты:

- `open.er-api.com` — бесплатно, без ключа, обновление раз в сутки.
- `frankfurter.app` — бесплатно, без ключа, open source, курсы ЕЦБ.
- `exchangerate-api.com` — бесплатный тариф с ключом (до 1500 запросов/мес).

---

## 1. Apple Shortcuts (ярлык на Home Screen) — самый простой

Без единой строчки кода. В приложении **Shortcuts** на iPhone:

1. Блок «Get Contents of URL» → бесплатный API (например `frankfurter.app`).
2. Блок «Get Dictionary Value» → достать нужный курс из JSON.
3. Блок «Quick Look» / «Show Result» → показать результат.
4. «Add to Home Screen» — получаем иконку-конвертер на рабочем столе.

Плюсы: 10–15 минут, не нужен Mac/Xcode, полностью бесплатно.
Минусы: это не «живой» виджет (нужно тапнуть), интерфейс минимальный.

---

## 2. Scriptable-виджет (JS) — как `vocab-iphone-widget`

Тот же стек, что уже используется в `projects/vocab-iphone-widget/`:
приложение **Scriptable** (бесплатное, App Store), сам виджет — JS-скрипт.

- Скрипт раз в N часов дёргает `frankfurter.app`/`open.er-api.com`, кладёт
  результат в `Keychain`/файл, рисует `ListWidget` с парой курсов (USD→RUB,
  EUR→RUB и т.п.).
- Обновление через `WidgetKit` reload timeline, как в `WordOfDayCore.js`.
- Можно сделать интерактивный режим: тап по виджету открывает Scriptable
  с полем ввода суммы и мгновенным пересчётом.

Плюсы: реальный виджет на Home Screen, полностью бесплатно, код на JS,
переиспользуем паттерны из существующего проекта в этом workspace.
Минусы: Scriptable — сторонний рантайм, не «настоящий» нативный виджет,
обновления виджета ограничены системой (не чаще, чем раз в 15–30 мин).

---

## 3. PWA (веб-страница «как приложение»)

Простая HTML/CSS/JS страница с полем ввода суммы, селектором валют и
запросом к бесплатному API. Хостинг — GitHub Pages/Cloudflare Pages/Vercel
(бесплатный тариф). Добавляется на Home Screen через Safari → «На экран
Домой» — получаем иконку, открывающую полноэкранный «псевдо-нативный» апп.
С `manifest.json` + `service worker` можно закешировать последний курс и
работать офлайн.

Плюсы: полноценный UI, кроссплатформенно (то же самое откроется и на
Android), не нужен Xcode, версионирование в Git.
Минусы: не настоящий виджет (только иконка-ссылка), нужен браузерный движок.

---

## 4. No-code конструкторы приложений (Glide / Adalo / Thunkable)

Собираем экран с полями ввода и API-запросом в конструкторе (drag-and-drop),
бесплатный тариф достаточен для личного проекта. Приложение ставится на
телефон через тестовую ссылку/QR или TestFlight-аналог конструктора.

Плюсы: быстрее нативной разработки, не требует кода вообще.
Минусы: бесплатный тариф обычно с ограничениями (branding, лимит
пользователей/запросов), меньше контроля над виджетом на Home Screen.

---

## 5. Нативный виджет: SwiftUI + WidgetKit — как `english-word-widget-kids`

Тот же стек, что во втором проекте этого workspace. Нужен Mac с Xcode
(бесплатный) и Apple ID (бесплатная локальная установка на своё устройство
через Xcode — Developer Program за $99/год нужен только для публикации в
App Store, не для личного использования).

- `TimelineProvider` раз в час запрашивает курс и обновляет таймлайн виджета.
- Полноценный SwiftUI UI, поддержка размеров виджета (small/medium/large),
  в iOS 17+ можно сделать **интерактивный** виджет (кнопки/поле ввода прямо
  в виджете через `AppIntent`, без открытия приложения).
- Данные можно расширить: история курса, график, избранные пары валют.

Плюсы: самый качественный UX, «настоящий» системный виджет, максимум
возможностей (интерактивность, App Group для шаринга данных с приложением).
Минусы: нужен Mac, знание Swift/SwiftUI, дольше в разработке.

---

## 6. Полноценное кроссплатформенное приложение (Flutter / React Native)

Если в итоге нужен не только виджет, а полноценный апп (история конвертаций,
избранные валюты, офлайн-режим, push-уведомления о курсе):

- **Flutter** или **React Native** — бесплатные open-source фреймворки,
  один код для iOS и Android.
- Установка на своё устройство — бесплатно (через Xcode/Android Studio).
- Публикация в сторы — по желанию, платно: Apple $99/год, Google Play $25
  разово. Для личного использования не нужна.
- Виджет на Home Screen в этом случае всё равно придётся делать отдельно
  нативным модулем (WidgetKit для iOS, App Widget для Android), пункт 5
  выше плюс аналог на Kotlin.

Плюсы: максимум функциональности, кроссплатформенность, готово к росту
в «настоящий» продукт.
Минусы: самый долгий путь, требует полноценной разработки приложения,
отдельная работа над виджетом (widget ≠ app).

---

## Рекомендация по шагам

Если это разовая идея — начать с **варианта 1 (Shortcuts)** за 15 минут,
чтобы проверить, нужна ли вообще такая штука на Home Screen. Если да —
делать **вариант 2 (Scriptable)**, переиспользуя опыт `vocab-iphone-widget`.
Если продукт «прижился» и хочется красивый нативный виджет — переходить
к **варианту 5 (SwiftUI + WidgetKit)**, как это уже сделано в
`english-word-widget-kids`.
