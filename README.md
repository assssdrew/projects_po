# projects_po

Тематический workspace для проектов PO.

## Структура

| Папка | Назначение |
|-------|------------|
| `knowledge/` | База знаний, материалы, ссылки |
| `projects/` | Рабочие проекты и артефакты |
| `notes/` | Быстрые заметки |

## Cursor

- ПК: папка в `screepts/workspaces.code-workspace` как **projects_po**
- Телефон: Add Workspace → GitHub `assssdrew/projects_po`
- В чате: `@projects_po`
